## Featured Project

### 서울 부동산 가격정보 서비스

아파트 가격과 거래동향 데이터를 조회하고, 사용자의 자연어 질문을 검색 조건으로 변환해 답변하는 서비스입니다.

- 담당: 백엔드 API, 자연어 질문 분석, 검색·응답 흐름 구현
- 주요 기능: 아파트 가격 조회, 지역·단지 검색, 거래동향 분석, 자연어 질의응답
- 인증: JWT 및 OAuth2 로그인
- 검색·데이터: JPA, MySQL, Elasticsearch, Parquet/MinIO 연동
- 품질: 질문 분석·검색·보안·도메인 서비스 테스트 작성
- 기술: Java 21, Spring Boot 4, Spring Data JPA, Elasticsearch, MySQL, Docker
